# Assistente Virtual

Uma IA para Windows que **enxerga sua tela** e só fala quando ajuda: avisa do inimigo chegando
por trás, aponta o erro no seu código, responde perguntas olhando o que está na tela e, se você
pedir, usa o computador por você. Roda no seu PC, de graça, com a IA na sua placa de vídeo.

**⬇ Baixe em [mello13256.github.io/Assistente-Virtual](https://mello13256.github.io/Assistente-Virtual/)**
ou na [última versão](https://github.com/mello13256/Assistente-Virtual/releases/latest).

Este repositório guarda só o site e os instaladores. O código-fonte é privado.

Encontrou um problema? [Abra uma issue](https://github.com/mello13256/Assistente-Virtual/issues).
